Overview

WebGuard is a Python-based web security scanner that audits any public website for common HTTP security misconfigurations. It checks response headers, CORS settings, cookie flags, HTTPS enforcement, and server information leaks — then produces a scored report with colour-coded results and actionable recommendations.

The entire application runs in a single file (app.py) using only Python built-in libraries and Streamlit. No pandas, no numpy, no machine learning, and no external API keys are required.

How the Detection Logic Works

Header Check — Present = PASS, Missing = FAIL:

value = raw_headers.get(header_name.lower(), "")
if value:
    status = "PASS"
else:
    status = "FAIL"

CORS Check — Wildcard origin = dangerous:

acao = headers.get("access-control-allow-origin", "")
if acao == "*":
    return "FAIL", "Open CORS — any origin allowed"

Cookie Check — Must have Secure + HttpOnly flags:

if "secure" not in set_cookie.lower():
    issues.append("missing Secure flag")
if "httponly" not in set_cookie.lower():
    issues.append("missing HttpOnly flag")

Limitations

  • Only scans HTTP response headers — does not crawl page content
  • Cannot scan sites that require login or authentication
  • HTTPS redirect check may not work on all server configurations
  • Results reflect only one HTTP request — real audits need multiple scans
  • Not connected to any threat intelligence database

Conclusion

WebGuard demonstrates how a single Python file can perform meaningful web security auditing. The project covers key web security concepts from OWASP — including transport security, injection prevention, information disclosure, and cookie security — while remaining fully understandable to beginners.

Every check maps directly to a real-world attack type, making this project both educational and practically relevant to web security careers.
